# 小霸王街机厅 — 详情

在 DeepSeek Harness 里塞进一台街机柜。右下角出现「街机厅」按钮，点开后是一块带 CRT 扫描线的全屏画面，四款 FC 经典在同一个画布上切换。

## 四款游戏

- **超级玛丽**：横版卷轴平台游戏。踩敌人、顶砖块出金币、吃蘑菇变大（变大后受击只变小）、掉坑或侧面撞敌人掉命，三命用尽失败，到旗杆过关。
- **魂斗罗**：横版跑射。八方向射击（按住方向决定枪口朝向）、巡逻士兵与固定炮台、中弹即死并短暂无敌重生，关卡末有带血条的 BOSS。
- **炸弹人**：网格炸弹对战。炸弹 2 秒引爆、十字火柱、相邻炸弹连锁；砖块有概率掉「炸弹数 +1 / 威力 +1」，清空敌人后出口开启。
- **淘金者**：经典爬梯解谜。收齐金块让出口显形；脚下可以挖坑困住守卫（6 秒后砖块恢复，守卫卡 4 秒），两只守卫会主动追人。

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 移动（魂斗罗中同时决定射击方向） |
| Z / 空格 | 跳跃、确认、重开 |
| X / K | 射击、放炸弹、挖坑 |
| Enter | 重新开始当前游戏 |
| Esc | 关闭街机厅 |

顶栏提供音效开关、重开和关闭；音效偏好保存在浏览器本地。

## 实现

- Host 半侧只注册一个 `/dsh-arcade` 静态路由，把 `public/` 下的页面发给浏览器。
- Client 半侧注入右下角按钮，点开时挂一个全屏 iframe；页面用 `postMessage('dsh-arcade:close')` 通知关闭。
- 游戏页是纯 HTML + Canvas 2D，无任何第三方库、无外部图片/音频资源，像素画全部由代码绘制，音效由 WebAudio 实时合成。
- 每个游戏是一个独立模块，遵循统一的 `create(host)` 契约（`reset/update/draw`），外壳负责输入、固定时间步、HUD 和异常兜底。

## 限制

- 四款游戏是致敬式复刻，关卡与数值重新设计，**不是**原版 ROM 或反汇编代码移植。
- 仅支持键盘，无触屏与手柄。
- 画布逻辑分辨率 640×400，按容器等比缩放；音效需要一次用户点击后才会解锁（浏览器自动播放策略）。
